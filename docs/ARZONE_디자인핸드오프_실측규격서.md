# ARZONE 디자인 핸드오프 — 실측 규격서

> 대상: 디자이너
> 목적: 프론트/AR 개발과 1:1로 맞물리는 **측정 가능한 규격** 제공
> 대상 기기: ① **Galaxy S26 Ultra** (2D 화면) · ② **Meta Quest 3 512GB** (월드공간)
> 원칙: 값을 임의로 정하지 말고 아래 스케일/단위를 따를 것. 모든 토큰은 Figma Variables로, 라이트·다크 둘 다.

---

## 0. 공통 규칙

- **스마트폰 단위**: `pt`(iOS) / `dp`(Android) — 동일 수치로 간주. 디자인 @1x, export @2x·@3x.
- **AR 단위**: **dmm** = 1m 거리에서의 mm (거리 독립 단위, Meta 표준). 실측 = `dmm × 거리(m)`.
- **각도↔크기 변환 공식**(어떤 거리든 계산 가능):
  `실제크기(mm) = 2 × 거리(mm) × tan(각도/2)`
  → 1.5m 기준 **1° ≈ 26mm**, **1dmm ≈ 0.017° … 즉 1° ≈ 17.5dmm**
- 폰 수치를 AR로 **그대로 옮기지 말 것**(px↔cm 직결 금지). 반드시 위 공식으로 재계산.
- 아래 수치는 **기준/목표값**. 특히 AR 텍스트 가독성은 **실기기에서 최종 캘리브레이션**한다.

## 2. AR 글라스 규격 — Meta Quest 3 (512GB)

기기 디스플레이: 눈당 **2064 × 2208 px** (LCD·팬케이크), **25 PPD**, 시야각 **110° H × 96° V**, 최대 120Hz. (저장 512GB는 UI 규격과 무관)

> **기준 거리 1.5 m** (콘텐츠 기본 배치 거리). 아래 실측 mm는 모두 1.5m 기준.
> 콘텐츠 배치 거리는 **1.0–2.0 m** 허용, **0.5 m 미만 금지**(눈 피로).
> 참고: 25 PPD → 1px ≈ 0.04° ≈ 0.7 dmm. 시야각 ±55°(H)가 화면 물리적 끝.

### 2.1 텍스트 (각도 우선 → dmm → 1.5m 실측)
| 역할 | 시야각 | dmm | 1.5m 실측 |
|---|---|---|---|
| 하한(아이콘 라벨) | 1.0° | ~17.5 | **~26 mm** |
| **본문 최소** | 1.2° | ~21 | **~31 mm** |
| 본문 권장 | 1.5° | ~26 | ~39 mm |
| 타이틀 | 2.2–3.0° | ~38–52 | ~57–79 mm |

> Quest 3 해상도 ~25 PPD 기준. **얇은 획(< ~2 dmm) 금지** — 렌더에서 사라짐.

### 2.2 인터랙션 타깃 (핸드 레이 + 핀치)
| 항목 | 시야각 | dmm | 1.5m 실측 |
|---|---|---|---|
| **최소 버튼** | 2.0° | ~35 | **~52 mm** |
| 권장 버튼 | 3.0° | ~52 | ~78 mm |
| 타깃 간 간격 | ≥ 0.5° | ~9 | ~13 mm |

### 2.3 패널 · 레이아웃
| 항목 | 값 |
|---|---|
| **기본 패널 폭** | 시야각 20–40° → 1.5m서 **0.53–1.09 m** (허브 권장 ~30° ≈ **0.8 m**) |
| 패널 곡률 | 사용자 중심 실린더, **반경 = 배치 거리(1.5 m)** (모든 지점 등거리) |
| 콘텐츠 높이 | 시선 중심에서 **약 −10°(살짝 아래)** — 목 편안 |
| 근접 조작(직접 잡기) | **0.35–0.6 m** (팔 닿는 거리) |

### 2.4 편안 영역 (시선 중심 기준)
| 축 | 편안(머리 안 움직임) | 최대(가벼운 head turn) | 금지 |
|---|---|---|---|
| 수평 | ±15–20° | ±30° | > ±55° |
| 수직 | +20° ~ −20° | — | 위로 오래 보기 |

### 2.5 실물 스케일 콘텐츠 (패스스루)
| 항목 | 값 |
|---|---|
| 무대·오브젝트 | **실제 크기 1:1**, 감지된 바닥 평면 위 |
| 아바타 키 | **1.6–1.8 m** (실제 사람 스케일) |
| 사용자 이동 | 무대 주위 걸어서 관람 가능하게 여백 확보 |

## 3. 반드시 함께 지킬 것

### 3.1 피규어 정면 아트 — 인식 요건 (기술 제약, 협의 불가)
- **무광(matte) · 고대비 · 디테일 풍부**
- **큰 단색 면 금지**, **반복 패턴 금지** (특징점이 없어 인식 실패)
- 수락 기준: 정면 렌더 전달 → **개발이 인식 테스트로 통과/반려**

### 3.2 폰↔AR 공용 자산
- 색·타이포 **토큰은 공유**, 다만 **크기 수치는 각 규격서 기준으로 별도** (px↔dmm 직결 금지)
- 3D/AR 에셋은 **성능 예산 표**를 별도 요청: 폴리곤 수 / 텍스처 크기 / 드로우콜 상한 (Quest는 스테레오라 더 빡셈)

### 3.3 핸드오프 형식
- Figma **Dev Mode** 단일 소스, 모든 컴포넌트 **상태 전부**(default/hover/press/disabled/loading/empty/error)
- 변경 시 **변경 로그** 남길 것
