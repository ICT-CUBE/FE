# 블렌더버전 VRM에 셰이프키(얼굴 움직임) 만들기

2026-08-31. 대상: `블렌더버전.vrm` (= Untitled (1).vrm, 셰이프키 0개라 얼굴이 못 움직이는 모델).

## 먼저 알아둘 것 — 딱 2개만 만들면 된다

앱이 실제로 움직이는 표정은 이것뿐이다:

| VRM 표정 | 하는 일 | 앱에서 쓰는 곳 |
|---|---|---|
| `aa` | 입 벌리기 | AR감상 립싱크 (음량 따라 입 여닫음) |
| `blink` | 양쪽 눈 감기 | 홈·AR 눈깜빡임 (AvatarBlink) |

ih/ou/ee/oh 같은 나머지 입모양은 앱이 안 쓰니 안 만들어도 된다.
(나중에 정밀 립싱크를 하고 싶어지면 그때 추가하면 됨.)

## 준비물

1. **블렌더** (이미 있음 — 이 모델을 블렌더에서 export했으니)
2. **VRM Add-on for Blender** (무료) — https://vrm-addon-for-blender.info
   - VRM을 export한 적 있으면 이미 깔려 있다. 없으면: 사이트에서 zip 받기 → 블렌더 `Edit > Preferences > Add-ons > Install` → zip 선택 → 체크박스 켜기
3. 모델의 **원본 .blend 파일** (있으면 그걸 열기). 없으면 `File > Import > VRM`으로 블렌더버전.vrm을 불러온다.

## 1단계 — 얼굴 메시 찾기

이 모델은 메시가 22개로 쪼개져 있다. 오른쪽 위 아웃라이너에서 오브젝트를
하나씩 클릭해보며 **얼굴 피부(눈꺼풀·입술 포함)가 들어있는 메시**를 찾는다.
클릭하면 뷰포트에서 주황색으로 하이라이트되니 금방 안다.
눈꺼풀과 입술이 다른 메시에 나뉘어 있으면 각 메시에 각각 만들면 된다
(blink는 눈꺼풀 메시에, aa는 입 메시에).

## 2단계 — 셰이프키 슬롯 만들기

1. 얼굴 메시를 선택한 상태에서 오른쪽 프로퍼티 패널의 **초록 역삼각형 탭**
   (Object Data Properties)을 연다.
2. **Shape Keys** 섹션에서 `+` 를 **두 번** 누른다.
   - 첫 번째 = `Basis` (원본 얼굴, 절대 건드리지 말 것)
   - 두 번째 = `Key 1` → 더블클릭해서 이름을 **`blink`** 로 바꾼다.
3. `+` 를 한 번 더 눌러 세 번째 키를 만들고 이름을 **`aa`** 로 바꾼다.

## 3단계 — blink (눈 감기) 조각하기

1. Shape Keys 목록에서 **blink 를 선택**하고, 그 아래 **Value 슬라이더를 1.0**으로 올린다.
   (지금은 Basis와 똑같으니 아무 변화 없음 — 정상)
2. `Tab` 키로 **Edit Mode** 진입.
3. `O` 키로 **비례 편집(Proportional Editing)** 켜기 (헤더의 동심원 아이콘이 파랗게 됨).
4. 뷰를 얼굴 정면으로 돌리고(`넘패드 1`), **윗눈꺼풀 가장자리 버텍스**를 클릭 →
   `G` → `Z` 로 아래로 끌어 눈을 덮는다.
   - 마우스 휠로 비례 편집 반경(회색 원)을 조절 — 눈꺼풀만 따라오게 작게.
   - 눈알을 뚫고 들어가면 안 되니 옆에서도(`넘패드 3`) 확인하며 눈알 표면을 감싸듯.
5. 양쪽 눈 다 한다. (편집 전에 헤더의 **나비 아이콘(X축 미러)**를 켜두면 한쪽만 해도 반대쪽이 따라온다 — 모델이 좌우대칭일 때만 먹힘)
6. `Tab` 으로 Object Mode 복귀 → **Value 를 0으로 되돌린다.**
7. 검증: Value 슬라이더를 0↔1 왔다갔다 — 눈이 자연스럽게 감기면 성공.

## 4단계 — aa (입 벌리기) 조각하기

1. Shape Keys에서 **aa 선택**, Value 1.0.
2. Edit Mode → 비례 편집 켠 채로 **아래턱·아랫입술 부분 버텍스**를 잡고
   `G` → `Z` 로 아래로 내려 입을 벌린다. "아—" 발음 정도(과하지 않게).
   - 윗입술은 거의 고정, 아랫입술+턱살이 같이 내려오는 게 자연스럽다.
   - 입 안이 비어 보이면 그대로 둬도 된다(폰 화면에선 잘 안 보임). 이빨 메시가 따로 있으면 아랫니 메시에도 같은 이름 `aa` 키를 만들어 같이 내린다.
3. Object Mode → Value 0으로 되돌리기 → 슬라이더로 검증.

> **주의**: Value를 0으로 안 돌려놓고 export하면 입 벌린 채 굳은 모델이 나온다.

## 5단계 — VRM 표정에 연결하기

셰이프키만 만들면 안 되고, VRM의 `aa`/`blink` **표정에 바인딩**해야 유니티가 쓴다.

1. 아웃라이너에서 **Armature(뼈대)** 를 선택한다.
2. 프로퍼티 패널 **오브젝트 탭**(주황 네모)에 VRM 애드온 섹션이 있다 →
   **VRM 1.0 > Expressions** 를 편다.
3. **aa** 항목 → `Morph Target Binds` 의 `+` → Mesh = 얼굴 메시, Shape Key = `aa`, Value = 1.0
4. **blink** 항목 → 같은 방식으로 Shape Key = `blink`, Value = 1.0
   (눈꺼풀이 별도 메시면 그 메시를 지정)

## 6단계 — Export & 나한테 전달

1. `File > Export > VRM (.vrm)` — **VRM 1.0** 인지 확인하고 export.
2. 파일명 아무거나 (예: `avatar_blender_face.vrm`) → **Downloads에 두고 나한테 말해줘.**
   내가 셰이프키·바인딩이 제대로 들어갔는지 바이너리로 검증하고 프로젝트에 넣을게.
   (지금 앱은 vroid 모델을 쓰고 있으니, 교체는 검증 후에 씬 배선까지 같이.)

## 더 편한 길 (선택지)

- **FaceIt 애드온 (유료, 약 $100)**: 얼굴 랜드마크만 찍으면 ARKit 52개
  셰이프키를 자동 생성해준다. 표정 전부(웃음·화남 등)까지 원하면 이게 제일 빠름.
  aa·blink 2개만 필요한 지금은 수작업이 더 싸고 충분하다.
- **VRoid Studio로 다시 만들기**: VRoid에서 export한 모델은 셰이프키가 처음부터
  전부 들어있다(지금 앱의 vroid 모델이 그렇다). 블렌더버전의 외형을 포기할 수 있으면
  이쪽이 제로 작업.

## 함정 모음

- **Basis 키를 편집하면 망한다** — 편집 전 Shape Keys 목록에서 어느 키가 선택돼 있는지 항상 확인.
- **Value 0으로 되돌리고 export** (위 4단계 주의 참조).
- **비례 편집 반경**이 크면 코·볼까지 따라 움직인다 — 회색 원을 눈/입 크기로.
- 미러(나비 아이콘)는 메시가 정확히 좌우대칭일 때만 작동 — 안 먹으면 양쪽 수동.
- export 시 "Only Selections" 같은 옵션이 켜져 있으면 메시가 빠질 수 있다 — 기본값으로.
