# ARZONE — 프론트엔드 기능 명세서

> ARZONE Special Edition AR Album CUBE · 한이음 드림업 · 작성 2026-08-31
> 플랫폼: Android (Unity 6000.3.17f1 · URP · IL2CPP · ARCore + Vuforia)
> 기준 해상도 412×893 (디자인 시안 실측 기반 구현)

## 1. 제품 개요

실물 피규어(큐브)를 소유한 팬이 폰 카메라로 피규어를 인증하면, AR 아바타(제니)와
상호작용하는 팬덤 앨범 앱. 핵심 루프: **실물 인증 → AR 소환/감상 → 촬영·기록 → 대화·커뮤니티**.

## 2. 구현 기능 목록 (도메인별)

### 2-1. 인증·온보딩
| 기능 | 설명 |
|---|---|
| 스플래시·온보딩 슬라이드 | 3장 스와이프 + 인디케이터, 최종 디자인 에셋 적용 |
| 이메일 회원가입 | 닉네임·프로필 캐릭터 3종 선택, 성공 시에만 진행 |
| 이메일 로그인 | 형식 검증·비밀번호 보기 토글 |
| 자동 로그인 | 토큰 영속(재실행 유지), 만료 시 자동으로 로그인 화면 복귀 |
| 로그아웃·탈퇴 | 확인 모달, 토큰 제거 후 로그인 화면 |
| 실물 피규어 인식(큐브 인증) | Vuforia Model Target + 자체 위조 검증(아래 4장) |
| 인증 코드 입력 | 대체 인증 경로 — 4자리 커스텀 키패드·제한시간 |

### 2-2. 홈·허브·아바타
| 기능 | 설명 |
|---|---|
| 홈 | 3D 아바타 무대(앉은 포즈)·인사말 로테이션·D-day·친밀도 카드 |
| 아바타 홈 | 무대에 선 아바타(시안 실측 프레이밍)·대화/소환 진입 |
| 허브 | 콘텐츠 허브 — D-day/아티스트 표기 홈과 통일 |
| 화면별 아바타 포즈 | 앉기(홈)·스탠딩(아바타홈)·환영(음성대화)·V사인(AR소환) — 본 단위 정적 포즈 시스템 |
| 아바타 페이스 | 자동 눈깜빡임 + 립싱크 (VRM 표정 — 셰이프키 제작·바인딩 포함) |
| 친밀도 | 레벨·XP·주간 그래프·혜택 — 진행바는 디자이너 216프레임 시퀀스를 실측 매핑해 수치와 픽셀 단위 일치 |

### 2-3. 대화 (텍스트·음성)
| 기능 | 설명 |
|---|---|
| 텍스트 대화 | 세션·메시지·AI 생성 응답, 낙관적 말풍선(실패 시 회수) |
| 대화 목록·검색·보관함·신고·삭제 | 검색은 전 세션 메시지 대상, 스와이프 삭제 |

| 음성 대화 STT | Android 내장 음성 인식(JNI 직접 브리지, ko-KR), 연속 사용 안정화(자동 재시도) |
| 음성 대화 TTS | 아바타 응답 음성 재생 + 무대 아바타 립싱크 |
| 음성 대화 화면 | 듣는 중 파형 · 내 말은 글 길이에 맞는 자동 크기 상자 · 응답은 상단 대사 교체 |

### 2-4. AR
| 기능 | 설명 |
|---|---|
| AR 소환 | 평면 스캔→탭 배치(V사인)→드래그 재배치→예절샷 프레임 촬영→리포트 |

## 3. 공통 UX 기능
- **뒤로가기**: 히스토리 스택이 아닌 **고정 부모 맵**(55항목) — 무한 루프 원천 차단
- **입력 필드**: 인라인 편집(커서 이동·한 글자 삭제), 보라색(#A855F7) 캐럿 1초 점멸
- **키보드 리프트**: 하단 입력 UI 전부 키보드 높이만큼 상승(기기별 실측 대응)
- **전송 버튼**: PointerDown 처리 — 키보드 닫힘으로 인한 클릭 유실 방지
- **토스트·바텀시트·모달**: 공통 컴포넌트(스와이프 닫기·여백 탭 닫기)
- **유리(glass) 질감**: 정점 그라디언트 + 발광 부분 테두리로 시안 재현

## 4. 실물 인증(위조 방지) 설계 — 자체 개발
Vuforia는 추적기일 뿐 정품 판별 기능이 없어(부분 가림 허용 설계) 다음을 자체 구현:
1. **연속 관측** — 2.5초간 끊김 없는 TRACKED 상태 요구
2. **거리 안정성** — 카메라↔대상 거리 흔들림 5cm 초과 시 리셋(사진·부분 형상은 포즈 추정이 널뜀. 상위 15% 아웃라이어 트림)
3. **전체 프레이밍** — 머리~발끝이 화면 안에 있어야 판정
4. **다리 픽셀 검증** — 판정 순간 화면 캡처, 다리 구역 9점 vs 옆 배경 색 비교 — 다리 잘린 피규어 차단
5. **사용자 피드백** — 실루엣 가이드(항상 표시)·실제 진행률 게이지(단조 증가)

좌표계 함정 2건을 실측으로 해결: Vuforia 월드가 카메라 고정·대상 이동 좌표계인 점(상대좌표 측정으로 전환),
월드 1유닛=1cm 인 점(단위 보정 상수).

## 5. 성능 실측 (Galaxy S25급, Adreno 840)
- 아바타 189만 트라이앵글(고품질 모델): 홈/AR 소환/AR 감상 전 구간 **30fps 고정**(AR 상한)
- 소환 순간 1회성 ~0.5초 로드
